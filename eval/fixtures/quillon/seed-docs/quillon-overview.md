# Quillon

Quillon is a small command line tool that turns a folder of markdown entries into an Atom feed and a static site.

Commands: `quillon build` renders the site, `quillon check` validates the entries, `quillon serve` previews it.

See [[testing]] for the test suite and [[build-output]] for what a build produces.
